Course Management System 🎓

Course Management System is a web application built with Spring Boot that allows users to register and log in as either a teacher or a student. Students can access and learn courses, while teachers can manage and monitor their students effectively.

Features ✨

👩‍🏫 Teacher Role:

Create, update, and delete courses.

Manage student enrollments.

Monitor student progress and performance.

🎓 Student Role:

Enroll in available courses.

Access and learn course materials.

Track their progress.

🔒 Authentication & Authorization:

Secure login and registration using Spring Security 6 and JWT.

📦 Database Management:

Integrated with PostgreSQL for data persistence.

Database migrations handled via Liquibase.

⚡ Caching:

Optimized performance using Redis for caching.

📖 API Documentation:

Comprehensive API documentation available via Swagger.

Technologies Used 🛠️

Backend Framework: Spring Boot 3.3.3

Database: PostgreSQL

Object Relational Mapping: MyBatis

Security: Spring Security 6, JWT Authentication

Database Migrations: Liquibase

Caching: Redis

API Documentation: Swagger

Build Tool: Maven

Installation and Setup 🚀

Requirements:

Java 17+

Maven 3.8+

PostgreSQL

Redis
